## 二、Python 和 C / Java 最不一样的五件事（30 节里最重要的一张表）

| 事 | C / Java | Python |
|---|---|---|
| 语句结尾 | `;` 必须有 | 没有分号，**回车即结束** |
| 代码块 | `{ ... }` 花括号 | **缩进 4 空格**，缩错直接语法错 |
| 声明变量 | `int x = 5;` | `x = 5`，不写类型，Python 自己认 |
| 怎么跑 | 先编译（gcc / javac）再运行 | **解释器直接跑**，没有编译这步 |
| 注释 | `//` 和 `/* */` | `#`（只有单行，没有块注释） |

**类比**：C / Java 的花括号是「围墙」，圈住代码块；Python 的缩进是「楼梯台阶」——同一层台阶就是同一层代码，台阶错一格（缩进不一致），整栋楼塌（`SyntaxError` / `TabError`）。

> 为什么敢这么设计？因为写 C / Java 时你也本来就被要求缩进对齐。区别只是：C / Java 里缩进是**礼貌**，Python 里缩进是**法律**。

## 三、print 的四个细节

1. `print` 是**内置函数**，不用 import（C 要 `#include <stdio.h>`，Java 要 `System.out.println`，Python 啥都不用）。
2. 引号**单双随意**：`'hello'` 和 `"hello"` 完全等价（C 只认双引号）。习惯：默认双引号，字符串里要嵌套引号时换单引号。
3. **逗号 = 自动加空格**：`print("hello", "world")` 打出 `hello world`，相当于 C 的 `printf("%s %s", ...)` 但不用写格式符。
4. 打印变量**不加引号**：`print(x)` 打值，`print("x")` 打字母 x。

## 七、进阶实验室（2026-11-11 加量版，建议今天啃完）

敲 `py` 进 REPL（`>>>` 提示符），逐行做实验，每行都想一下「C 里要怎么写」：

| 在 `>>>` 里敲 | 你会看到 | 在干嘛 |
|---|---|---|
| `"abc" * 3` | `'abcabcabc'` | 字符串乘法 = 重复，C 里想都别想 |
| `"abc" + "def"` | `'abcdef'` | 字符串加法 = 拼接 |
| `10 / 3` | `3.3333333333333335` | 一根斜杠 = **真除法，永远给小数**。C 的 `10/3=3` 整除陷阱在 Python 不存在 |
| `10 // 3` | `3` | 双斜杠 = 地板除，只要整数部分 |
| `2 ** 10` | `1024` | 双星号 = 乘方。C 要 `pow(2,10)` 还得 include |
| `type(5)` | `<class 'int'>` | 查类型——Day 2 正课，先混脸熟 |
| `type(3.14)` / `type("a")` / `type(True)` | float / str / bool | 同上 |
| `x = 5` 回车 → `x = "hi"` 回车 → `x` | `'hi'` | **动态类型**：同一个变量名能换着装，C 里这是违规操作 |

### 故意翻车三部曲（重点：学会读报错）

新手最值钱的技能不是不报错，是**看懂报错**。主动制造三个：

1. `print(1 + "a")` → `TypeError: unsupported operand type(s) for +: 'int' and 'str'`——数字不能直接加字符串（Python 连 `+` 都不肯帮你隐式转）
2. 把 `day1_hello.py` 第 17 行 `    print("x 比 3 大")` 行首的 4 个空格删掉，`py code\day1_hello.py` → `IndentationError`——缩进法律的现场执法，看完改回来
3. 在 REPL 敲 `print(“hi”)`（中文引号）→ `SyntaxError`，注意报错里 `^` 小箭头指向出错的那一格

**读报错口诀：从最后一行往上读。** 最后一行 = 什么错（类型 + 原因），行号和 `^` = 错在哪。玩完 `exit()` 退出。
