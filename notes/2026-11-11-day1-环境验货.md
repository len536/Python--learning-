## 二、Python 和 C / Java 最不一样的五件事（30 节里最重要的一张表）

| 事 | C / Java | Python |
|---|---|---|
| 语句结尾 | `;` 必须有 | 没有分号，**回车即结束** |
| 代码块 | `{ ... }` 花括号 | **缩进 4 空格**，缩错直接语法错 |
| 声明变量 | `int x = 5;` | `x = 5`，不写类型，Python 自己认 |
| 怎么跑 | 先编译（gcc / javac）再运行 | **解释器直接跑**，没有编译这步 |
| 注释 | `//` 和 `/* */` | `#`（只有单行，没有块注释） |

**类比**：C / Java 的花括号是「围墙」，圈住代码块；Python 的缩进是「楼梯台阶」——同一层台阶就是同一层代码，台阶错一格（缩进不一致），整栋楼塌（`SyntaxError` / `TabError`）。

> 为什么敢这么设计？因为写 C / Java 时你也本来就被要求缩进对齐。区别只是：C / Java 里缩进是**礼貌**，Python 里缩进是**法律**。

## 三、print 的四个细节

1. `print` 是**内置函数**，不用 import（C 要 `#include <stdio.h>`，Java 要 `System.out.println`，Python 啥都不用）。
2. 引号**单双随意**：`'hello'` 和 `"hello"` 完全等价（C 只认双引号）。习惯：默认双引号，字符串里要嵌套引号时换单引号。
3. **逗号 = 自动加空格**：`print("hello", "world")` 打出 `hello world`，相当于 C 的 `printf("%s %s", ...)` 但不用写格式符。
4. 打印变量**不加引号**：`print(x)` 打值，`print("x")` 打字母 x。

## 四、交互模式（REPL）vs 脚本

| | REPL（敲 `py` 进去） | .py 文件 |
|---|---|---|
| 怎么用 | 敲一行，立刻出结果 | 整个文件一起跑 |
| 适合 | 当计算器、试一句语法对不对 | 正式代码，反复跑 |
| 类比 | 草稿纸 | 作业本 |

`>>>` 是 REPL 提示符。今天可以进去随便玩：`1 + 1`、`"abc" * 3`（会有惊喜）、`exit()` 退出。

## 六、踩坑清单（今天可能撞上的）

| 坑 | 症状 | 原因 / 解法 |
|---|---|---|
| 中文引号 | `SyntaxError`，报错位置在字符串附近 | 输入法中文状态敲了 `“”`。**写代码切英文输入法** |
| 缩进混用 | `TabError: inconsistent use of tabs and spaces` | tab 和空格混了。**统一 4 空格**，VSCode 默认就是 |
| 路径写法 | CMD 里 `cd /d/...` 报「命令语法不正确」 | CMD 用 `\`，切盘 `cd /d D:\...`（昨天翻过一次车） |
