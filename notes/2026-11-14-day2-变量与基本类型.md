## 一、变量：不是盒子，是标签（今天最重要的观念）

C / Java 里，变量是**盒子**：`int x = 5;` 先造一个只能装 int 的盒子，把 5 塞进去。盒子有类型，终身不改。

Python 里，变量是**贴在东西上的标签**：`x = 5` 是把标签 `x` 贴到整数对象 `5` 上。标签本身没有类型，随时可以撕下来贴到别的东西上：

```python
x = 5          # 标签 x 贴在整数 5 上
x = "hello"    # 撕下来，贴到字符串 "hello" 上 —— 完全合法
```

这在 C 里是编译错误（`int` 盒子装不了字符串），在 Java 里也得靠声明 `Object x` 绕。Python 之所以敢这样：**Python 里一切皆对象**，标签贴谁都是贴对象。

| | C / Java | Python |
|---|---|---|
| 变量本质 | 有类型有地址的盒子 | 指向对象的**名字（标签）** |
| 声明 | `int x;` 必须先声明 | 没有声明这回事，**赋值即创建** |
| 换类型 | 编译错误 | 合法（动态类型） |
| `x = x + 1` | 盒子里的值 +1 | 造个新对象 6，标签 x 重新贴上去 |

**类比**：宿舍床位牌。C 的床位牌刻死了「这张床只能住大一的」；Python 的床位牌是张磁贴，今天贴张三明天贴李四都行。但**磁贴本身不是人**——变量不是数据本身，只是指过去的手指。

## 二、五大基本类型

| 类型 | 写法 | C / Java 对照 | 注意点 |
|---|---|---|---|
| `int` 整数 | `5`、`-3`、`0` | `int` / `long` | **任意大，永不过溢出**（见进阶） |
| `float` 浮点 | `3.14`、`-0.5` | `double`（不是 C 的 `float`！） | 有精度坑 `0.1 + 0.2 != 0.3`（见进阶） |
| `str` 字符串 | `"abc"`、`'abc'` | `char[]` / `String` | 单双引号等价；**不可变**（Day 3 细讲） |
| `bool` 布尔 | `True` / `False` | `bool` | **首字母大写**！`true`/`false` 会报 NameError |
| `None` 空值 | `None` | Java 的 `null` / C 的 `NULL` | 表示「什么都没有」，不是 0 也不是空串 |

三个最容易栽的：

1. **`True` 大写**。C 写小写 `true`（C99），Java 写小写 `true`，Python 偏偏大写。写错报 `NameError: name 'true' is not defined`。
2. **`None` ≠ 0 ≠ ""**。判断是不是 None 要用 `x is None`，不要用 `x == None`（进阶讲 is 和 == 的区别）。
3. **Python 的 float 精度是 double 级**，别被名字骗了；反过来 C 的 `float` 才是低精度那档。

## 三、type() 和 isinstance()：给对象验明正身

```python
type(5)        # <class 'int'>
type(3.14)     # <class 'float'>
type("hi")     # <class 'str'>
type(True)     # <class 'bool'>
type(None)     # <class 'NoneType'>

isinstance(5, int)      # True
isinstance(True, int)   # True！居然（见进阶：bool 是 int 的子类）
```

`type()` 回答「它是什么」；`isinstance(x, 类型)` 回答「它是不是这个类型（或其子类）」。日常判断用 `isinstance`，它认亲戚（继承）。

## 四、input()：永远返回字符串（新手第一杀手坑）

```python
age = input("请输入年龄：")    # 你敲 18
type(age)                     # <class 'str'> ！！
```

**`input()` 拿到的东西永远是 `str`**，哪怕你敲的是数字。所以：

```python
age + 1        # TypeError: can only concatenate str to str —— 直接翻车
age = int(age) # 转成整数（int() 是把字符串"翻译"成数字）
age + 1        # 19，OK
```

| 写法 | 作用 | 翻车现场 |
|---|---|---|
| `int("18")` | 字符串 → 整数 | `int("18.5")` 报 ValueError，得先 `float()` |
| `float("3.14")` | 字符串 → 浮点 | `float("abc")` 报 ValueError |
| `str(18)` | 数字 → 字符串 | 拼接 `"年龄" + str(18)` |
| `int(3.99)` | 浮点 → 整数 | **直接砍尾巴 = 3，不四舍五入**！要四舍五入用 `round(3.99)` |

**类比**：`input()` 像快递签收——不管箱子里是书还是砖头，签收单上写的都是「包裹」。想用里面的东西，得拆箱（`int()`）。

## 五、f-string：字符串格式化的现代标准

C 的 `printf("%s is %d", name, age)` 你熟。Python 3.6+ 的答案是 **f-string**：字符串前加个 `f`，里面 `{}` 直接放变量：

```python
name = "冷"
score = 92.5678
print(f"{name} 的成绩是 {score}")           # 冷 的成绩是 92.5678
print(f"{name} 的成绩是 {score:.2f}")       # 92.57 —— .2f 保留两位，四舍五入
print(f"[{name:>10}]")                      # 右对齐占 10 格
print(f"[{name:<10}]")                      # 左对齐占 10 格
print(f"{score=}")                          # 输出 score=92.5678，调试神器
```

| 写法 | C 的 printf 对照 | 意思 |
|---|---|---|
| `f"{x}"` | `"%d", x` | 直接嵌入 |
| `f"{x:.2f}"` | `"%.2f", x` | 保留 2 位小数 |
| `f"{x:>8}"` / `f"{x:<8}"` | `"%8d"` / `%-8d"` | 右 / 左对齐占 8 格 |
| `f"{x=}"` | 没有对应 | 变量名和值一起打，调试用 |

老式写法 `%` 和 `.format()` 以后读别人代码会遇到，能看懂就行，自己写一律 f-string。

## 六、动态类型：好处与代价

**好处**：不用声明、随手赋值，写得飞快——脚本、数据处理爽到飞起。

**代价**：类型错误**运行时才爆**，编译期没人拦你。C/Java 编译器当场骂你，Python 要等跑起来才炸。所以正经 Python 项目会用类型注解（Day 18 顺带讲）和测试（Day 25）来兜底。

**类比**：静态类型像食堂大妈先看饭卡余额再打饭；动态类型像先打完饭、走到收银台才发现钱不够——爽是爽了，翻车在后头。

## 七、进阶实验室（REPL 里逐条敲，敲前先猜结果）

```python
# 1. 整数无溢出：C 里 int 上限 2^31-1 ≈ 21 亿，Python 不设限
2 ** 100                    # 一个 31 位的天文数字，照算不误

# 2. float 精度坑：0.1 在二进制里是无限循环小数，存不准
0.1 + 0.2                   # 0.30000000000000004 ！
0.1 + 0.2 == 0.3            # False ！
round(0.1 + 0.2, 6) == 0.3  # True —— 所以比浮点相等要 round 一下

# 3. bool 是 int 的子类（惊不惊喜）
True + True                 # 2 ！True 就是 1
isinstance(True, int)       # True
sum([True, False, True])    # 2 —— 可以数列表里 True 的个数，很常用

# 4. is 和 == 的区别：== 比「值」，is 比「同一个对象」（同一块内存）
a = [1, 2]; b = [1, 2]
a == b                      # True：内容一样
a is b                      # False：两个不同的列表对象
c = a
c is a                      # True：标签指同一个东西
x = 256; y = 256
x is y                      # True（小整数 -5~256 Python 缓存复用）
x = 257; y = 257
x is y                      # False！所以判断 None 用 is，判断值用 ==
```

**为什么判 None 用 `is None`**：`==` 可以被自定义类改写行为（Day 19），`is` 不会被改，永远老老实实回答「是不是同一个对象」。None 全局只有一个，所以 `x is None` 是唯一稳妥写法。

**选做**：`py` 进 REPL 敲 `id(5)`、`id(5.0)`、`id("a")` 看对象编号；再敲 `x = 5` → `id(x)` → `x = 6` → `id(x)`，亲眼看到「标签换了对象」（编号变了）。

## 八、踩坑速记

| 坑 | 症状 | 一句话解法 |
|---|---|---|
| `true` 小写 | `NameError` | Python 要 `True` / `False` |
| `input()` 数字直接运算 | `TypeError` | `int(input(...))` 拆箱 |
| `int(3.99)` | 得 3 不是 4 | 砍尾巴不四舍五入，要 `round()` |
| `int("3.14")` | `ValueError` | 先 `float("3.14")` |
| 浮点直接 `==` | 偶尔 False | `round(a, 6) == round(b, 6)` |
| 判 None 用 `==` | 以后被自定义类坑 | 一律 `x is None` |
