### 三层练习，一层都不能少

| 层级 | 是什么 | 放哪 | 验收标准 |
|------|--------|------|----------|
| 节级 | 当堂小练习，10-30 行，练单个知识点 | `code\dayN_xxx.py` | `py code\dayN_xxx.py` 能跑出预期结果 |
| **阶段级** | 一个完整小工具，能用、有输入输出、有错误处理 | `projects\stageN-名字\` | 别人照着 README 能跑起来 |

### 每个阶段项目的最低要求

1. 目录里有自己的 `README.md`：做什么、怎么跑、用到哪些知识点、踩过的坑。
2. 至少 **3 次 commit**：搭骨架 → 加功能 → 修 bug，不要一次性 dump 全部代码。
3. 完成时打 tag：`git tag stage1`。
4. 代码能跑通再提交，不提交跑不起来的代码。

### Git 节奏（照着做，别堆到最后）

| 时机 | 命令 | 说明 |
|------|------|------|
| 每学完一节 | `git add .` → `git commit -m "feat(day3): 字符串切片练习"` | 一天至少一次，别攒一周 |
| 阶段项目完成 | `git commit -m "feat(stage1): 命令行计算器"` → `git tag stage1` | 打 tag 方便回看里程碑 |
| 想同步到 GitHub | `git push origin main --tags` | 走 SSH，本机已认证，不用镜像 |
| 看历史 | `git log --oneline --graph --all` | 一眼看清自己走了多远 |

### commit message 规范（沿用 Git 课的约定）

| 前缀 | 什么时候用 |
|------|-----------|
| `feat` | 新增功能 / 新练习 |
| `fix` | 修 bug |
| `docs` | 笔记、README |
| `refactor` | 重写但不改功能 |
| `chore` | 配置、杂项 |

带作用域更清楚：`feat(day12): kwargs 打包练习`、`fix(stage2): 排名并列时顺序错乱`。

## 环境（已就绪，Day 1 只需验货，不用重装）

本机 2026-09-20 已装官方 Python 3.13.15 到 `%LOCALAPPDATA%\Programs\Python\Python313`，PATH 和 `py` 启动器都配好了。2026-11-08 实测可用。

```bash
py --version                  # 看版本，Windows 专用启动器，自动找到你装的官方 Python
py -m pip --version           # 看包管理器版本，-m 表示「用这个解释器去跑 pip 模块」
py -m pip list                # 列出已装的第三方库
py code/day1_hello.py         # 用官方解释器跑脚本
```

| 写法 | 含义 |
|------|------|
| `py` | Windows 的 Python 启动器，按已安装版本挑解释器，比直接敲 `python` 稳 |
| `-m pip` | `-m` = module，让当前解释器执行 `pip` 模块，确保包装到**同一个**解释器下 |
| `pip install xxx` | 装第三方库；国内慢就加 `-i https://mirrors.huaweicloud.com/repository/pypi/simple` |
| `py -m venv .venv` | 建虚拟环境（Day 21 细讲），给项目隔离依赖 |

### ⚠️ 本机专属坑：别直接敲 `python`

2026-11-03 实测，在 WorkBuddy 终端里 `python` 命中的是 **WorkBuddy 自带的 managed 版 3.13.14**（`C:/Users/ASUS/.workbuddy/binaries/python/versions/3.13.12/`），不是你自己装的那份。用它 `pip install` 会把库装进 `.workbuddy` 目录（违反「长期环境一律装自己路径下」的规矩），换终端行为还可能不一样。

| 命令 | 实际指向 | 结论 |
|------|----------|------|
| `py` | 官方 3.13.15，`%LOCALAPPDATA%\Programs\Python\Python313\` | ✅ **一直用这个** |
| `python`（WorkBuddy 终端） | managed 3.13.14，`.workbuddy\binaries\python\` | ❌ 只当临时脚本环境 |

统一用 `py` 和 `py -m pip`。确认没走错：`py -c "import sys; print(sys.executable)"`，路径带 `AppData\Local\Programs\Python` 就对。
